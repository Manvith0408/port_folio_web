# Web Developer Portfolio - Manvith A.A.

Personal portfolio website built with HTML, CSS, Bootstrap, and JavaScript.

## Features:
* **Light/Dark Modes Supported 🌙☀️:** Switch effortlessly between light and dark themes.
* **Modern & Clean Design 👍:** Responsive layout with modern aesthetics and smooth animations.
* **Optimized for Performance 🚀:** SEO metadata, preloading, and fast asset delivery.
* **Showcase Sections:** About Me, Skills, Projects, and Contact form.

## Technologies Used:
* HTML5, CSS3, JavaScript
* Bootstrap 5 & Bootstrap Icons
* AOS (Animate on Scroll)
* Owl Carousel & jQuery
